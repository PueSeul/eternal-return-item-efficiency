# 이터널 리턴 아이템별 가격대비 효율 계산기

## 목적

이터널 리턴에서 장비 조합을 바꿨을 때 **스킬 한 방의 데미지가 얼마나 늘고, 그 증가가 가격에 비해 얼마나 효율적인지**를
숫자로 비교하는 Windows 프로그램입니다. 무기·머리·옷·팔·다리 5칸에 아이템을 넣으면 실험체·숙련도·스킬·상대 방어력을 반영한
최종 피해량(D)과, 기준 세트 대비 가격 효율(%)을 계산합니다.

## 현재 사용 가능한 기능

- **장비 5슬롯**: 무기·머리·옷·팔·다리에 아이템을 하나씩 장착(이름 검색, 등급·가격 표시, 패치노트로 바뀐 아이템은 "패치 반영" 표식).
- **기준 세트 비교**: "데미지 효율 계산 기준" 5칸에 기준 세트를 고르면 같은 입력값으로 두 세트를 계산해
  가격 합·데미지 총량·가격당 데미지를 기준/현재/차이 표로 보여 줍니다(다음 실행에도 유지, "기준 비우기"로 해제).
- **효율**: 기준 대비 가격 효율 %, 기준 가격 합이 0이면 가격당 추가 데미지(아래 계산식).
- **히스토리**: 계산할 때마다 저장되고 "최근순"·"최고 효율순"으로 볼 수 있으며, 클릭하면 구성·입력값·기준 세트가 복원됩니다.
- **실험체·숙련도 자동 입력**: 실험체·캐릭터 레벨·숙련도 레벨을 고르면 아이템 외 공격력, 아이템 외 % 스킬 증폭을 자동으로 채웁니다(손으로 고칠 수 있음).
- **스킬 선택 자동 입력**: 실험체의 스킬과 스킬 레벨을 고르면 스킬 기본 피해량·공격력 계수·스킬 증폭 계수를 채웁니다(나무위키 수치, 패치노트 반영 표시).
- **방어 관통**: 아이템의 방어 관통율·방어 관통과 입력란의 추가 방어 관통율(%)·추가 방어 관통(고정)을 함께 반영합니다.
- **데이터 업데이트**: dak.gg 아이템·실험체 수치, 최신 공식 패치노트, 나무위키 스킬 수치(전체 실험체)를 **매일 12:00(한국 시간)**
  자동으로 수집해 이 저장소의 `data-latest` 릴리스에 올립니다(06:00에는 스킬을 뺀 아이템·실험체·패치노트만 한 번 더 갱신). 위쪽 "아이템 업데이트" 버튼은 이 데이터를 받아(보통 10초 이내)
  파일 검증(sha256) 뒤 exe 옆 `data/` 폴더에 저장하고 바로 반영합니다. 이미 최신이면 파일을 바꾸지 않습니다.
  GitHub에 접속하지 못하면 dak.gg·패치노트에서 직접 수집하고(스킬은 패치노트에 나온 실험체만, 약 40초) 완료 문구에 그 사실을 표시합니다.
  "스킬 전체 다시 수집"은 지금 바로 모든 실험체를 나무위키에서 다시 읽습니다(약 2분). 진행 단계가 표시되고, 실패하면 기존 데이터를 그대로 두고 어느 단계에서 왜 실패했는지 보여 줍니다.
- **프로그램 자동 업데이트**: 시작할 때 GitHub Releases에서 새 버전을 확인해 위쪽에 "새 버전 vX.Y.Z — 지금 업데이트" 배너를 띄웁니다.
  "지금 업데이트"를 누르면 새 exe를 받고(진행률 표시) 프로그램이 스스로 교체·재시작합니다. 아래 "자동 업데이트" 참고.

## 계산식

```
SA = (스킬 증폭 고정 합 + 레벨 당 스킬 증폭 × 캐릭터 레벨 + 아이템 외 스킬 증폭)
     × max(0.1, 1 + % 스킬 증폭 합 + 아이템 외 % 스킬 증폭)
S  = 스킬 기본 피해량 + 공격력 계수 × 공격력 합 + 스킬 증폭 계수 × SA
     공격력 합 = 공격력 + 레벨 당 공격력 × 캐릭터 레벨 + 아이템 외 공격력
R' = max(0, R × (1 − 방어 관통율 합) − 방어 관통 합)
     방어 관통율 합·방어 관통 합 = 아이템 합 + 입력란의 추가 방어 관통율(%)·추가 방어 관통(고정)
B  = S × 100 / (100 + R')
D  = max(1, B × M × K)
     M = max(0.1, 1 + 최종 피해 증가율 합 + 추가 피해 증가 − 대상 피해 감소)
     K = 1 − 대상 스킬 피해 감소
```

- R은 피격 대상 방어력으로 기본값이 없어 직접 입력합니다. 스킬 기본 피해량·공격력 계수·스킬 증폭 계수도 기본값이 없어 직접 입력하거나 스킬 선택으로 채웁니다.
- % 입력란(% 스킬 증폭, 방어 관통율, 피해 증가·감소 등)은 퍼센트 단위로 넣고 식에서는 100으로 나눈 비율로 씁니다(예: 94% → 0.94). 공격력·스킬 증폭 계수도 같습니다.
- 아이템 스탯 매핑: `스킬 증폭`·`레벨 당 스킬 증폭`·`스킬 증폭(택1)` → SA의 고정 합, `스킬 증폭율`·`(고유) 스킬 증폭` → SA의 % 합,
  `공격력`·`레벨 당 공격력`·`공격력(택1)` → 공격력 합, `방어 관통율`·`방어 관통` → R', `최종 피해 증가율` → M. 그 밖의 스탯은 식에 들어가지 않습니다.
- 실험체 자동 입력: 아이템 외 공격력 = `attackPower + attackPowerPerLevel × (캐릭터 레벨 − 1)`,
  아이템 외 % 스킬 증폭(%) = 무기 숙련도 `skillAmpRatio × 숙련도 레벨 × 100`(예: 0.047 × 20 × 100 = 94, 무기 종류는 무기 슬롯 아이템으로 결정).
  "아이템 외 스킬 증폭"(고정)은 자동으로 채우지 않으니, 화면의 **현재 스킬 증폭 합계**(= SA)가 게임 스탯창 값과 같아지도록 맞춰 넣으세요.
- 검산: 아르다(아르카나 숙련 20, 레벨 20) + 여제·쿤달라·이단심판관·임세티·글레이셜 슈즈 → SA 430 × (1 + 0.15 + 0.94) = 898.7(스탯창 898),
  스킬 기본 피해량 230, 스킬 증폭 계수 80%, R 150 → D 379.58 (인게임 측정 379).

**택1 규칙**: `공격력(택1)`/`스킬 증폭(택1)`은 한쪽만 더합니다. 무기를 뺀 4부위(머리·옷·팔·다리) 중
공격력 계열(`공격력`, `레벨 당 공격력`)을 가진 부위 수 a와 스킬 증폭 계열(`스킬 증폭`, `레벨 당 스킬 증폭`, `(고유) 스킬 증폭`)을 가진 부위 수 s를 세어
(한 아이템이 둘 다 가지면 둘 다 셈, 값 0은 세지 않음) **a > s면 공격력(택1), 그 외(동률 포함)는 스킬 증폭(택1)** 을 적용합니다.

**효율 %** = (현재 세트 D ÷ 현재 가격 합) ÷ (기준 세트 D ÷ 기준 가격 합) × 100.

- 기준 세트 5칸이 다 차 있지 않으면 히스토리 중 최고 (D ÷ 가격 합)을 100%로 한 예전 방식으로 계산하고 그렇게 표시합니다.
- **기준 가격 합이 0**이면 효율 % 대신 **가격당 추가 데미지** = (현재 D − 기준 D) ÷ 현재 가격 합(소수 4자리)을 보여 주고, 현재 가격 합도 0이면 "—"입니다.
- 기록에는 계산 당시의 기준 세트와 효율 값·방식이 저장되며, "최고 효율순"은 같은 방식끼리 정렬합니다(효율 % → 가격당 추가 데미지 → 값 없음).
  계산식이 바뀌기 전 기록은 "이전 계산식 기록"으로 표시되고 최고치 비교에서 빠지며, 최고 효율순에서는 값 없는 기록과 함께 맨 뒤에 놓입니다.

### 데이터 출처와 우선순위

| 파일 | 출처 | 우선순위 |
|---|---|---|
| `data/items.json` | dak.gg 아이템 API | 최신 공식 패치노트(이후 핫픽스 포함)와 값이 다르면 **패치노트 값** |
| `data/characters.json` | dak.gg 실험체·숙련도 API | 패치노트에 바뀐 수치가 있으면 **패치노트 값** |
| `data/skills.json` | 나무위키 실험체 문서의 스킬 수치 | 패치노트 값은 **나무위키 문서가 패치노트 게시 전에 마지막으로 수정된 경우에만** 덮어씀 |
| `data/items.meta.json` | 위 수집의 출처·패치 버전·덮어쓴 수치·해석하지 못한 문구 | 제목 아래 "데이터: …" 줄을 누르면 반영 내역을 볼 수 있음 |

- 가격은 `data/price_table.json`의 값입니다(지정한 아이템은 재료 기준 가격 또는 사용자 지정 가격, 초월(신화)은 일괄 500, 나머지는 등급 기반 대체값). 각 아이템의 `priceSource`와 선택 목록에 표시됩니다.
- 프로그램은 exe 옆 `data/`의 파일을 먼저 읽고, 없으면 exe에 들어 있는 빌드 당시 데이터를 씁니다.
- 저장소의 `data/`와 [`data-latest` 릴리스](https://github.com/PueSeul/eternal-return-item-efficiency/releases/tag/data-latest)는
  매일 자동 갱신됩니다(바뀐 내용이 있을 때만 `data/` 커밋). 12:00(한국 시간)에는 관리자 PC의 작업 스케줄러가 전체(나무위키 스킬 포함)를,
  06:00에는 GitHub Actions가 아이템·실험체·패치노트만(나무위키가 GitHub 서버의 접속을 막아 스킬은 그대로) 수집합니다.
  관리자 PC가 꺼져 있던 날은 다음에 켜질 때 수집합니다. 릴리스의 `data-manifest.json`에 수집 시각과 파일별 sha256이 들어 있습니다.
- 나무위키 수집은 robots.txt를 지키고 요청 시작 간격을 1초 이상 둡니다. 나무위키 내용의 라이선스는 CC BY-NC-SA 2.0 KR입니다.

## 다운로드와 실행

1. [Releases 최신 버전](https://github.com/PueSeul/eternal-return-item-efficiency/releases/latest)에서
   `ER-Damage-Calculator-<버전>-portable.exe`를 받습니다.
2. 원하는 폴더에 두고 더블클릭합니다(설치 없음). 첫 실행은 압축을 푸느라 몇 초 걸릴 수 있습니다.
3. 서명되지 않은 exe라 **Windows SmartScreen**("Windows의 PC 보호") 경고가 뜨면 **"추가 정보 → 실행"** 을 누르세요.

- 히스토리와 기준 세트는 `%APPDATA%\er-damage-efficiency-v2`에 저장되어 exe를 옮기거나 새 버전으로 바꿔도 유지됩니다.
- "아이템 업데이트"로 받은 데이터는 exe 옆 `data/` 폴더에 저장됩니다. exe를 옮길 때 이 폴더도 함께 옮기세요.

### 자동 업데이트

- 시작할 때 한 번 [GitHub Releases 최신 릴리스](https://api.github.com/repos/PueSeul/eternal-return-item-efficiency/releases/latest)를
  확인해 현재 버전보다 높으면 배너를 띄웁니다. 위쪽 **"업데이트 확인"** 버튼으로 언제든 다시 확인할 수 있습니다.
- **"지금 업데이트"**: 새 exe를 현재 exe 옆에 릴리스 파일 이름(예: `ER-Damage-Calculator-1.3.0-portable.exe`)으로 받고,
  새 exe를 실행한 뒤 현재 프로그램이 종료됩니다. 새 exe가 이전 프로그램이 끝나기를 기다려 이전 exe를 지웁니다
  (명령 프롬프트 창은 뜨지 않습니다). 1.1.0에서 업데이트해 파일 이름만 옛 버전으로 남아 있으면 처음 실행할 때 올바른 이름으로 한 번 바꿔 다시 시작합니다.
- 받기나 새 exe 실행에 실패하면 받은 파일을 지우고 현재 버전을 그대로 쓰며 배너에 이유를 보여 줍니다.
  새 버전이 이전 exe를 지우지 못하면 이전 exe는 그대로 남고 새 버전 화면에 알려 줍니다.
- **"나중에"**: 이번 실행에서는 그 버전을 시작 알림으로 다시 띄우지 않습니다(다음 실행 때 다시 확인, "업데이트 확인"을 직접 누르면 다시 보임).
- 확인·설치는 portable exe에서 동작합니다.
