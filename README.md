# 이터널 리턴 아이템 가격 대비 데미지 효율 계산기

무기·머리·옷·팔·다리 5개 슬롯에 아이템을 하나씩 장착하고, 스킬 데미지 총량(D)과
가격 대비 데미지 효율(%)을 계산합니다. 계산 기록은 브라우저에 저장되고, 클릭하면 다시 불러옵니다.

## 실행 방법

필요한 것: [Node.js](https://nodejs.org/) 18 이상 (설치 외 추가 패키지 없음)

```
npm start
```

브라우저가 자동으로 `http://127.0.0.1:5173/` 을 엽니다. 종료는 터미널에서 `Ctrl+C`.

- `index.html`을 더블클릭해서 열면 보안 제한 때문에 데이터 파일을 읽지 못합니다. 꼭 `npm start`로 실행하세요.
- 히스토리는 브라우저 localStorage에 주소(포트 포함)별로 저장됩니다. 포트를 바꾸면(`PORT` 환경변수) 기록이 따로 보입니다.

## 프로그램 실행/빌드 (Windows exe)

Node.js 없이 더블클릭으로 쓰려면 exe를 만듭니다. 빌드하는 PC에만 Node.js 22.12 이상이 필요하고
(처음 한 번 `npm install`), 만든 exe는 Node.js 없이 실행됩니다.

```
npm run build:exe
```

v2 계산식용 별도 exe(`dist/ER-Damage-Calculator-v2-1.0.0-portable.exe`, 창 제목에 v2):

```
npm run build:exe:v2
```

v2 exe는 히스토리를 따로 저장하고(`%APPDATA%\er-damage-efficiency-v2`), exe 옆 `data/items.json` 우선 읽기와
"아이템 수치 업데이트" 버튼은 v1과 같습니다. 개발 창에서 v2를 보려면 환경변수 `ER_FORMULA=v2`를 주고 `npm run app`.

- 결과물: `dist/ER-Damage-Calculator-1.0.0-portable.exe` (설치 없이 더블클릭으로 실행되는 단일 파일, 약 100MB)
- 개발 중 창으로 바로 띄워 보기: `npm run app`
- 첫 실행은 압축을 푸느라 몇 초 걸릴 수 있습니다. 서명되지 않은 exe라 Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.
- 히스토리는 `%APPDATA%\er-damage-efficiency`에 저장되어 exe를 옮기거나 새로 빌드해도 유지됩니다.
  (브라우저용 `npm start`의 히스토리와는 따로 저장됩니다.)
- **데이터 갱신**: exe에는 빌드 당시의 `data/items.json`이 들어 있습니다. exe와 같은 폴더에
  `data/items.json`이 있으면 그 파일을 우선 읽습니다.
  - 가장 쉬운 방법: 프로그램 위쪽 **"아이템 수치 업데이트"** 버튼을 누르면 최신 수치(패치노트 반영)를 인터넷에서 받아
    exe 옆 `data/` 폴더에 `items.json`·`characters.json`·`items.meta.json` 세 파일을 저장하고 화면에 반영합니다
    (재빌드 불필요, 인터넷 연결 필요). 세 파일 모두 exe 옆 `data/`에 있으면 그쪽을 우선 읽습니다.
    실패하거나 받은 아이템·캐릭터가 0개면 기존 데이터는 그대로 두고 오류 메시지를 보여 줍니다.
    `npm run app`(개발 창)에서 누르면 프로젝트 `data/`의 세 파일을 갱신합니다.
  - 직접 받은 `data/items.json`을 exe 옆 `data` 폴더에 복사해도 됩니다. 재빌드해도 새 데이터가 들어갑니다.

## 아이템 데이터 갱신

아이템 데이터는 `data/items.json`(dak.gg에서 수집)을 읽습니다. 이 파일이 없거나 최신 패치로 바꾸고 싶으면:

```
python scripts/fetch_items.py
```

수집 스크립트와 `data/items.json`은 별도로 관리됩니다. 파일이 없으면 화면 위쪽에 안내가 뜹니다.
아이템 이미지는 dak.gg CDN 주소라서 오프라인에서는 이미지만 보이지 않고 계산은 그대로 됩니다.

`data/items.meta.json`(데이터 출처·패치노트 반영 내역)이 있으면 제목 아래에
"데이터: dak.gg 12.6.0 · 패치노트 12.6 · 갱신 2026-10-17 02:30" 한 줄이 보입니다(없으면 숨김).
그 줄을 누르면 **패치노트 반영 내역** 창에서 패치노트로 덮어쓴 수치("이름 — 스탯: dak.gg 값 → 패치노트 값")와
해석하지 못한 문구("확인 필요")를 볼 수 있고, 덮어쓴 스탯이 있는 아이템은 선택 목록과 슬롯에 "패치 반영" 표식이 붙습니다.
"아이템 수치 업데이트" 뒤에는 이 정보도 다시 읽습니다.

## 계산식

`D = (B × A + I) × F` (모드 증폭 제외, 루미아섬 기준)

| 항 | 식 | 들어가는 아이템 스탯 |
|---|---|---|
| S | 스킬 기본 피해량 + 공격력 계수(%) × 공격력 | `공격력`, `레벨 당 공격력` × 성장형 스탯(입력란, 기본 20) |
| R' | R × (1 − 방어 관통율) − 방어 관통, R = 피격 대상 방어력 (공식에 하한이 없어 음수 허용) | `방어 관통율`, `방어 관통` |
| B | S × 100 / (R' + 100) | — |
| A | 1 + 스킬 증폭율 − 적의 스킬 피해 감소율 (최솟값 0.1) | `스킬 증폭율`, `(고유) 스킬 증폭` |
| I | 스킬 증폭 합 − 적의 스킬 피해 감소(고정) | `스킬 증폭`, `레벨 당 스킬 증폭` × 성장형 스탯 |
| F | 1 + 최종 피해 증가율 − 적의 최종 피해 감소율 | `최종 피해 증가율` (+ 입력란의 추가값) |

매핑 근거: [공식 라운지 피해 공식(에펨코리아 전재)](https://www.fmkorea.com/7229909171),
[나무위키 이터널 리턴/가이드 — 피해 공식](https://namu.wiki/w/%EC%9D%B4%ED%84%B0%EB%84%90%20%EB%A6%AC%ED%84%B4/%EA%B0%80%EC%9D%B4%EB%93%9C).
두 자료 모두 스킬 피해를 `스킬에 정의된 피해 × 100 / (100 + 적용 방어력)`에서 시작하고, 공격력은 스킬 툴팁의 계수("+공격력의 50%" 등)로 S에 들어갑니다.
고정 스킬 증폭은 계산식 이미지 그대로 I 항에 더합니다(호스트 결정).

`공격력(택1)`/`스킬 증폭(택1)`은 자동으로 한쪽만 더합니다. 무기를 뺀 4부위(머리·옷·팔·다리) 중
공격력 계열(`공격력`, `레벨 당 공격력`)을 가진 부위 수 a와 스킬 증폭 계열(`스킬 증폭`, `레벨 당 스킬 증폭`, `(고유) 스킬 증폭`)을 가진 부위 수 s를 세어
(한 아이템이 둘 다 가지면 둘 다 셈, 값이 0인 스탯은 세지 않음) **a > s면 공격력(택1), 그 외(동률 포함)는 스킬 증폭(택1)** 을 적용합니다. 히스토리 복원 후 다시 계산할 때도 같은 규칙입니다.
화면에는 계산식 설명이 없으며 식·매핑·근거는 이 README에만 있습니다.
최종 피해량 D의 최솟값은 1입니다. 그 밖의 스탯은 식에 들어가지 않습니다.
스킬 기본 피해량·공격력 계수·방어력 R은 기본값이 없으니 스킬 툴팁과 상대를 보고 직접 입력하세요. I 항의 적의 스킬 피해 감소(고정)는 기본값 0이며 따로 수치를 입력할 수 있습니다. 적의 감소율과 레벨도 화면에서 입력합니다.

히스토리는 "최근순"과 "최고 효율순" 탭으로 볼 수 있고, 어느 쪽이든 기록을 클릭하면 구성과 입력값이 복원됩니다.

**효율 %** = (현재 세트 D ÷ 가격 합) ÷ (기준 세트 D ÷ 가격 합) × 100.
기준 세트는 "계산" 버튼 위 **데미지 효율 계산 기준** 5칸에서 고르며(다음 실행에도 유지, v1/v2 따로 저장, "기준 비우기"로 해제),
같은 입력값으로 두 세트를 각각 계산해 기준/현재/차이 비교 표(가격 합·데미지 총량·가격당 데미지)와 접을 수 있는 기준 세트 계산 과정을 보여 줍니다.
기준 세트가 5칸 다 차 있지 않으면 예전 방식(히스토리 중 최고 D ÷ 가격 합 대비, 최고가 100%)으로 계산하고 그렇게 표시합니다.
기준 가격 합이 0이면 효율 % 대신 **가격당 추가 데미지** = (현재 D − 기준 D) ÷ 현재 가격 합(소수 4자리, 예: 91.66 ÷ 1155 = 0.0794)을 보여 주고, 현재 가격 합도 0이면 "—"입니다.
기록에는 계산 당시의 기준 세트와 효율 값·방식(효율 % / 가격당 추가 데미지)이 저장되어 기록 행에 기준 아이콘이 작게 보이고, 클릭하면 기준 세트도 복원됩니다.
"최고 효율순"은 같은 방식끼리 저장된 값으로 정렬합니다(효율 % 기록 → 가격당 추가 데미지 기록 → 값 없는 기록 순).
계산식이 바뀌기 전 기록(택1 수동 선택 시절 포함)은 "이전 계산식 기록"으로 표시되고 최고치 계산과 최고 효율순 정렬에서 제외됩니다.
가격은 데이터 파일의 `price`이며, 그 정체는 각 아이템의 `priceSource`에 적혀 있고 화면의 아이템 선택 목록에도 표시됩니다.

## 계산식 v2 (별도 실행 변형)

같은 프로그램에서 새 계산식(v2)으로 계산합니다. 웹에서는 `npm start` 후 `http://127.0.0.1:5173/?formula=v2` 를 엽니다
(데스크톱 v2 exe는 `window.ER_FORMULA = 'v2'`로 켜짐). 제목에 "v2"가 붙고, 히스토리는 v1과 따로 저장됩니다.

```
SA = (스킬 증폭 고정 합 + 레벨 당 스킬 증폭 × 성장형 스탯 + 아이템 외 스킬 증폭)
     × (1 + % 스킬 증폭 합 + 아이템 외 % 스킬 증폭)               ← 배수 최솟값 0.1
S  = 스킬 기본 피해량 + 공격력 계수 × 공격력 합 + 스킬 증폭 계수 × SA
     (공격력 합 = 공격력 + 레벨 당 공격력 × 성장형 스탯 + 아이템 외 공격력)
R' = R × (1 − 방어 관통율 합) − 방어 관통 합
B  = S × 100 / (100 + R')
D  = B × (1 + 최종 피해 증가율 합 + 추가 피해 증가 − 대상 피해 감소)   ← 배수 최솟값 0.1
       × (1 − 대상 스킬 피해 감소)                                  ← D 최솟값 1
```

| 입력란 | 뜻 | 기본값 |
|---|---|---|
| 실험체 | 이름 검색으로 선택(`data/characters.json`). 선택하면 아래 아이템 외 공격력·% 스킬 증폭을 자동으로 채움 | 없음 |
| 캐릭터 레벨 | `레벨 당 …` 아이템 스탯과 실험체 공격력 성장에 함께 쓰는 레벨 | 20 |
| 숙련도 레벨 | 무기 숙련도 레벨(무기 종류는 무기 슬롯 아이템의 `weaponType`으로 자동 결정) | 20 |
| 스킬 기본 피해량 / 공격력 계수 (%) / 스킬 증폭 계수 (%) | 스킬 툴팁의 기본 피해와 "(+공격력의 X%)", "(+스킬 증폭의 X%)" | 없음(직접 입력) |
| 피격 대상 방어력 (R) | 상대 방어력 | 없음(직접 입력) |
| 아이템 외 공격력 / 아이템 외 스킬 증폭 | 캐릭터 기본·성장, 특성 등 아이템이 아닌 고정 수치 | 0 |
| 아이템 외 % 스킬 증폭 (%) | 무기 숙련도 등 아이템이 아닌 % 스킬 증폭 | 0 |
| 추가 피해 증가 (%) / 대상 피해 감소 (%) / 대상 스킬 피해 감소 (%) | 위 식의 각 항 | 0 |

**실험체 자동 입력**: 실험체·캐릭터 레벨·숙련도 레벨·무기를 바꾸면
아이템 외 공격력 = 실험체 `attackPower + attackPowerPerLevel × (캐릭터 레벨 − 1)`,
아이템 외 % 스킬 증폭 = 무기 숙련도 `skillAmpRatio × 숙련도 레벨`(아이템 %와 합산)로 채워지고, 칸 아래에 자동값 출처가 작게 표시됩니다.
채운 값은 손으로 고칠 수 있습니다("수동 수정됨" 표시). 실험체에 그 무기 숙련도가 없으면 경고를 띄우고 % 스킬 증폭 자동값은 0입니다.
실험체 데이터에는 기본 스킬 증폭이 없어 "아이템 외 스킬 증폭"은 자동으로 채우지 않습니다. `data/characters.json`이 없으면 자동 입력만 꺼지고 나머지는 그대로 동작합니다.
실험체·숙련도·레벨은 히스토리에 저장되어 복원됩니다.

"아이템 외 스킬 증폭" 옆의 **현재 스킬 증폭 합계**(= SA)를 게임 스탯창의 스킬 증폭 값과 같아지도록 맞춰 넣으면 됩니다.
아이템 스탯 매핑: `스킬 증폭`·`레벨 당 스킬 증폭`·`스킬 증폭(택1)` → SA의 고정 합, `스킬 증폭율`·`(고유) 스킬 증폭` → SA의 % 합,
`공격력`·`레벨 당 공격력`·`공격력(택1)` → 공격력 합, `방어 관통율`·`방어 관통` → R', `최종 피해 증가율` → 피해 배수. 택1 자동 규칙·효율 %·히스토리·계산 과정 표시는 v1과 같습니다.
검산: 아르다(아르카나 숙련 20, 레벨 20) + 여제·쿤달라·이단심판관·임세티·글레이셜 슈즈 → 스킬 증폭 합계 430 × (1 + 0.15 + 0.94) = 898.7(스탯창 898),
스킬 기본 피해량 230, 공격력 계수 0, 스킬 증폭 계수 80, R 150 → 379.58 (인게임 측정 379).
근거: [공식 라운지 피해 공식(에펨코리아 전재)](https://www.fmkorea.com/7229909171),
[나무위키 이터널 리턴/가이드](https://namu.wiki/w/%EC%9D%B4%ED%84%B0%EB%84%90%20%EB%A6%AC%ED%84%B4/%EA%B0%80%EC%9D%B4%EB%93%9C),
[나무위키 칼라(이터널 리턴)](https://namu.wiki/w/%EC%B9%BC%EB%9D%BC(%EC%9D%B4%ED%84%B0%EB%84%90%20%EB%A6%AC%ED%84%B4)) — % 스킬 증폭은 고정 스킬 증폭 합에 곱해지고, 스킬 증폭은 스킬 계수로만 피해에 들어갑니다.
