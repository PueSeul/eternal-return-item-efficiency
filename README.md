# 이터널 리턴 아이템 가격 대비 데미지 효율 계산기

무기·머리·옷·팔·다리 5개 슬롯에 아이템을 하나씩 장착하고, 스킬 데미지 총량(D)과
가격 대비 데미지 효율(%)을 계산합니다. 계산 기록은 브라우저에 저장되고, 클릭하면 다시 불러옵니다.

## 실행 방법

필요한 것: [Node.js](https://nodejs.org/) 18 이상 (설치 외 추가 패키지 없음)

```
npm start
```

브라우저가 자동으로 `http://127.0.0.1:5173/` 을 엽니다. 종료는 터미널에서 `Ctrl+C`.

- `index.html`을 더블클릭해서 열면 보안 제한 때문에 데이터 파일을 읽지 못합니다. 꼭 `npm start`로 실행하세요.
- 히스토리는 브라우저 localStorage에 주소(포트 포함)별로 저장됩니다. 포트를 바꾸면(`PORT` 환경변수) 기록이 따로 보입니다.

## 프로그램 실행/빌드 (Windows exe)

Node.js 없이 더블클릭으로 쓰려면 exe를 만듭니다. 빌드하는 PC에만 Node.js 22.12 이상이 필요하고
(처음 한 번 `npm install`), 만든 exe는 Node.js 없이 실행됩니다.

```
npm run build:exe
```

- 결과물: `dist/ER-Damage-Calculator-1.0.0-portable.exe` (설치 없이 더블클릭으로 실행되는 단일 파일, 약 100MB)
- 개발 중 창으로 바로 띄워 보기: `npm run app`
- 첫 실행은 압축을 푸느라 몇 초 걸릴 수 있습니다. 서명되지 않은 exe라 Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.
- 히스토리는 `%APPDATA%\er-damage-efficiency`에 저장되어 exe를 옮기거나 새로 빌드해도 유지됩니다.
  (브라우저용 `npm start`의 히스토리와는 따로 저장됩니다.)
- **데이터 갱신**: exe에는 빌드 당시의 `data/items.json`이 들어 있습니다. exe와 같은 폴더에
  `data/items.json`이 있으면 그 파일을 우선 읽으므로, 재빌드 없이 `python scripts/fetch_items.py`로 받은
  `data/items.json`을 exe 옆 `data` 폴더에 복사하면 됩니다. 재빌드해도 새 데이터가 들어갑니다.

## 아이템 데이터 갱신

아이템 데이터는 `data/items.json`(dak.gg에서 수집)을 읽습니다. 이 파일이 없거나 최신 패치로 바꾸고 싶으면:

```
python scripts/fetch_items.py
```

수집 스크립트와 `data/items.json`은 별도로 관리됩니다. 파일이 없으면 화면 위쪽에 안내가 뜹니다.
아이템 이미지는 dak.gg CDN 주소라서 오프라인에서는 이미지만 보이지 않고 계산은 그대로 됩니다.

## 계산식

`D = (B × A + I) × F` (모드 증폭 제외, 루미아섬 기준)

| 항 | 식 | 들어가는 아이템 스탯 |
|---|---|---|
| S | 스킬 기본 피해량 + 공격력 계수(%) × 공격력 | `공격력`, `레벨 당 공격력` × 레벨 |
| R' | R × (1 − 방어 관통율) − 방어 관통, R = 피격 대상 방어력 | `방어 관통율`, `방어 관통` |
| B | S × 100 / (R' + 100) | — |
| A | 1 + 스킬 증폭율 − 적의 스킬 피해 감소율 (최솟값 0.1) | `스킬 증폭율`, `(고유) 스킬 증폭` |
| I | 스킬 증폭 합 − 적의 스킬 피해 감소(고정) | `스킬 증폭`, `레벨 당 스킬 증폭` × 레벨 |
| F | 1 + 최종 피해 증가율 − 적의 최종 피해 감소율 | `최종 피해 증가율` (+ 입력란의 추가값) |

매핑 근거: [공식 라운지 피해 공식(에펨코리아 전재)](https://www.fmkorea.com/7229909171),
[나무위키 이터널 리턴/가이드 — 피해 공식](https://namu.wiki/w/%EC%9D%B4%ED%84%B0%EB%84%90%20%EB%A6%AC%ED%84%B4/%EA%B0%80%EC%9D%B4%EB%93%9C).
두 자료 모두 스킬 피해를 `스킬에 정의된 피해 × 100 / (100 + 적용 방어력)`에서 시작하고, 공격력은 스킬 툴팁의 계수("+공격력의 50%" 등)로 S에 들어갑니다.
고정 스킬 증폭은 계산식 이미지 그대로 I 항에 더합니다(호스트 결정).

`공격력(택1)`/`스킬 증폭(택1)`은 화면의 "'(택1)' 스탯 처리" 선택(기본: 스킬 증폭)에 따라 한쪽만 더합니다.
최종 피해량 D의 최솟값은 1입니다. 그 밖의 스탯은 식에 들어가지 않습니다.
스킬 기본 피해량·공격력 계수·방어력 R은 기본값이 없으니 스킬 툴팁과 상대를 보고 직접 입력하세요. I 항의 적의 스킬 피해 감소(고정)는 기본값 0이며 따로 수치를 입력할 수 있습니다. 적의 감소율과 레벨도 화면에서 입력합니다.

히스토리는 "최근순"과 "최고 효율순" 탭으로 볼 수 있고, 어느 쪽이든 기록을 클릭하면 구성과 입력값이 복원됩니다.

**효율 %** = (이번 D ÷ 장착 아이템 가격 합) ÷ (히스토리 중 최고 D ÷ 가격 합) × 100 — 기록 중 최고 효율이 100%입니다.
가격은 데이터 파일의 `price`이며, 그 정체는 각 아이템의 `priceSource`에 적혀 있고 화면 도움말에도 표시됩니다.
